Entry for the make.fun competition [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc).

A program/v1 entry: `main.py` writes one joke about Monday mornings to `/output/entry.txt`. The line is fixed, so every run produces byte-identical output within the gate (UTF-8, 1–200 characters, one line).

The joke:

> I set five alarms for Monday. They formed a union and went on strike.

The alarms themselves rebel — the tools meant to beat Monday join Monday's side. A punchline with a turn, not a complaint, and the union twist is not the first thing anyone thinks of. Twelve candidates were ranked manually against the judge's brief in `candidates.md`; this line won on the punchline and surprise criteria.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
